# `tools/`: the checks, the headless world, the editors, the generator

Read with the root `CLAUDE.md`; how to use these from the pane is `docs/testing.md`.

- `check.js`: the headless checks CI runs (`node tools/check.js`). `world.js`: the whole world under Node from the same files, printing the determinism hash (the pane's number; the world reads no window): `--devchest` for a pane with the chest on, `--roundtrip` proves the save (a world restored from its own save hashes as one never saved), `--bite` proves a bite lands with no page behind the world, `--players=2`. `savecache.js`: every kind of change on a chunk, the cached save against the world made afresh. `netsmooth.js`: `node tools/netsmooth.js`, how evenly a remote body is drawn on a guest under steady, alternating, random, and stalled frame arrivals, the old smoothing against `src/netsmooth.js` (#248), and a guest's arrows, drawn where each frame put them against stepped from their launch (#250). `pathbench.js`: `node tools/pathbench.js [N]`, the pathfinder's reused memory against the old allocating one over N searches on the valley, the times, the collections, and every path compared tile for tile (#124; `check.js` imports the old pathfinder from it). `chartwire.js`: what the chart costs on the wire, a player walking open land and the village, the changed cells against the same changes as whole chunks (#237). `profile.js`: `(await import("/tools/profile.js")).run(__game)`, the profile every engine move records.
- `checks/`: the pane's instruments, one file per `await __game.check("<name>")`: ground, determinism, rooms, light, eviction, sheets, layers, frame, sway, water, sleep, craft, wear, poses, burn, growth, players, cap, windows, apples, build, slots, tools, fishing, chop, reach, charcoal, cloth, farm, boil, floaters, highlight, hovercard, debuffs, smalltext, coop, decor, paintings, woods, atlas, takeall, dye, villagers, feel, arrows, talk, navrow, hidden, chart, farms, animals, hunting, keeping, fence, mine, food, immune, kindle, kit, siege, sight, torch, lantern, flare, wire, worlds, save, sync, melee, sound (the list is the folder).
- `validate-data.py`: `python -I tools/validate-data.py`, the data's checks.
- `mapgen/`: the vocabulary (`mapgen.py`) and the valley's description (`valley.py`; a place's `crops(rect, kinds, stages, seed, floor, skip)` plants a plot, `floor_farm_y` for furrows along y); `python -I tools/mapgen/valley.py` writes `data/maps/valley.json` (`docs/30` step 0; the map is generated, never typed).
- `mapgen/staging.py` writes `data/maps/staging.json`, a clearing made only for pictures (`docs/38` step 5, #110), and `shots.js` takes the site's background shots of it from the game's canvas (`?map=staging&nosave`, then `(await import("/tools/shots.js")).run(__game)`; saved under `screenshots/` by `serve.py`, the chosen ones kept in `docs/images/site/`; it refuses unless the canvas is 1920 by 1080, so size the pane first; `run(__game, SITE)` writes the two wide ones as half-size WebP for `data/site/`, the site's background).
- `status.html`: where everything is (#358), read live from GitHub on every load: main and the deploy, Michael's queue, the open pull requests, the milestones as the roadmap, the issues with no milestone, `docs/39`'s tags by issue, and `TODO.md`'s status block; the public API unauthenticated and the raw files on `main`, nothing stored or sent; at http://localhost:8010/tools/status.html and on the site at `cmzgame.github.io/cozy-medieval-zombies/tools/status.html`; it works while the repository is public, and needs reworking the day it goes private (its head comment).
- `layers.html` the layer editor, `hair.html` the older hair-only one (`docs/12`), `template.html` the character template exporter, `slice.html` the slicer that turns a painted template into layer files (`docs/28`), `sprites.html` the sprite browser and editor (any drawn sheet's pixels and anchors; a generated sprite saved as drawn; the game reloads a save at once), `fonts.html` the font sampler. All at http://localhost:8010/tools/<name>.
- `art-gen/`: the design agent's art generators, an archive kept and never run without Michael (#95, Michael, 2026-10-16; `docs/27`): `character/` the character painting scripts, and `village/`, `trees/`, `ground/`, `decals/`, `crops/`, `farm-water/`, `pumpkins/`, `well/` the rest as delivered, each from its zip (which version and why, and what never came, in `art-gen/README.md`). Each writes only into its own `out/`; copying its output into `data/art/` would replace the game's art and is Michael's call.
