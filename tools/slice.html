Slicer

A PNG painted over the character template (tools/template.html: eight facings, four cells across and two down, 192 x 288 each, at 4x) becomes one layer file the game wears (docs/12, docs/23 step 3a, docs/25). Each painted 4x block becomes one game pixel; each pixel is given to a part by where it lies: on the body, the part under it; off the body, the nearest free part of the slot (arms, hands, feet, head). The file is saved exactly as tools/layers.html would save it, into data/layers/<slot>/, and listed in that slot's index.
